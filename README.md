# Quantum-Algorithm-Simulation-Application
# Quantum Algorithm Simulation Software

A desktop-based Quantum Computing simulator built using Python, Tkinter, and Qiskit. The application provides an interactive graphical user interface for simulating and visualizing fundamental quantum algorithms.

## Features

- Interactive Tkinter GUI
- Quantum circuit visualization
- Measurement histogram visualization
- Adjustable number of qubits and shots
- Educational result explanations
- Support for multiple quantum algorithms

## Implemented Algorithms

### Deutsch-Jozsa Algorithm
Determines whether a hidden function is constant or balanced using quantum parallelism.

### Grover's Search Algorithm
Searches for a target state in an unsorted database using amplitude amplification.

### Bernstein-Vazirani Algorithm
Finds a hidden binary string using a single oracle query.

## Technologies Used

- Python
- Tkinter
- Qiskit
- Qiskit Aer
- Matplotlib
